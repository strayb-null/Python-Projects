# 🎃 Hangman (Jogo da Forca)

Clássico jogo de adivinhar palavras letra por letra. Um projeto de aprendizado para praticar manipulação de arquivos e estado do jogo em Python.

## 📌 Sobre

Implementação do **Hangman** como parte do meu processo de estudos. O objetivo foi praticar:

- Leitura de arquivos externos (`words.txt`)
- Validação rigorosa de entrada do usuário
- Gerenciamento de estado (letras usadas, erros, vitória)
- Exibição de arte ASCII no terminal

## 🎯 O Que o Jogo Faz

| Elemento  | Descrição                          |
| --------- | ---------------------------------- |
| **Objetivo** | Adivinhar a palavra antes de completar o desenho |
| **Vida**  | 6 palpites errados permitidos      |
| **Dicas** | Mostra letras já tentadas e estado atual da palavra |

O jogador digita letras para tentar revelar uma palavra secreta escolhida aleatoriamente de uma lista.


*Feito com dedicação, erros e muita prática.* 🚀
