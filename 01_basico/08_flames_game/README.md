📖 Sobre

O FLAMES é um jogo clássico de papel e caneta que determina o relacionamento entre duas pessoas com base nos seus nomes. Este projeto é uma implementação moderna, limpa e interativa em Python, pronta para rodar no terminal.

| Passo | Descrição                                                            |
| ----- | -------------------------------------------------------------------- |
| **1** | Os dois nomes são digitados e sanitizados (minúsculas, sem espaços). |
| **2** | Letras em comum entre os dois nomes são removidas uma a uma.         |
| **3** | O total de letras restantes define o "passo" de eliminação.          |
| **4** | As 6 categorias (`F-L-A-M-E-S`) são percorridas circularmente.       |
| **5** | A última categoria restante é o resultado!                           |
