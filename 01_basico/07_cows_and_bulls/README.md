# 🐮🐂 Cows and Bulls

Jogo clássico de decifrar códigos numéricos. Um projeto de aprendizado para praticar lógica de programação em Python.

## 📌 Sobre

Implementação do jogo **Cows and Bulls** (Vacas e Touros) como parte do meu processo de estudos. O objetivo foi praticar:

- Lógica de comparação dígito a dígito
- Validação de entrada do usuário
- Estruturação de funções
- Controle de fluxo com loops

## 🎯 O Que o Jogo Faz

| Elemento  | Descrição                          |
| --------- | ---------------------------------- |
| **Touro** | Dígito correto na posição correta  |
| **Vaca**  | Dígito correto na posição errada   |

O jogador deve adivinhar um número secreto de 4 dígitos sem repetição, recebendo dicas a cada chute.


## ⚠️ Observações

- Projeto focado em **aprendizado**
- Código pode não seguir todas as boas práticas
